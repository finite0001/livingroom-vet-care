# Living Room Vet logo kit

Use the full lockup where there is room for the tagline. For a profile picture, favicon, or compact header, use the house-and-pets mark. The profile export has room for a circular crop.

## Logo files

| File | Use |
| --- | --- |
| `vector/living-room-vet-logo.svg` | Full-color master with the original lettering and tagline. Opens as editable paths in Illustrator. |
| `vector/living-room-vet-mark.svg` | House, pets, sofa, and stethoscope without lettering. |
| `vector/living-room-vet-one-color.svg` | Full logo in one forest-green ink. |
| `vector/living-room-vet-reversed.svg` | Full logo in ivory for dark backgrounds. |
| `png/living-room-vet-logo-transparent.png` | Full logo on transparency, 2172 px wide. |
| `png/living-room-vet-mark-transparent.png` | Icon on transparency, 1600 px wide. |

## Color and source

| Color | Hex |
| --- | --- |
| Forest green | `#22492E` |

Adobe traced the supplied JPEG into editable paths. The artwork preserves the hand-drawn outlines and lettering, with the paper texture removed and the tagline darkened for readability. The social layouts reuse the traced artwork with solid backgrounds. The website uses the mark alongside live text and serves the 1200 × 630 card for link previews.
