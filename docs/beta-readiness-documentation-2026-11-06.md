# Beta documentation and feature map — November 6, 2026

Source baseline: `b8767ff2e560f23d884194b5e9f875c0c647532a` (`origin/main` at audit start). This is the documentation workstream of the beta audit, not a declaration of clinical acceptance or a substitute for execution results. It maps implemented surfaces to their operating guidance and identifies where old documents describe earlier releases.

## How to read the repository

- **Current procedure:** [deployment runbook](deployment-runbook.md), [environment manifest](environment-manifest.md), [deployment guard](deployment-environment.md), [owner checklist](launch-owner-action-checklist.md).
- **Feature contracts:** `docs/features/`, focused top-level documents, and the plans linked in the table below. A plan describes intended behavior; confirm its implementation and test evidence before treating it as shipped.
- **Dated receipts:** `docs/launch-evidence/`, `docs/evidence/`, `docs/controlled-drugs/`, and retained `evidence/` proof packages. A receipt proves only the revision, environment and workload it names.
- **Historical requirements:** the September [standalone matrix](standalone-feature-matrix-20260916.md), [original plan](../plans/2026-09-12-practice-platform/plan.md), [go-live archive](go-live-runbook-2026-09.md), and older sections of [commercial readiness](commercial-readiness.md). Do not treat old “missing,” “current,” or “not deployed” wording as a current finding.
- **Workspace verification:** [nonclinical integration review](beta-readiness-workspace-2026-11-06.md) and [dependency triage](beta-readiness-dependencies-2026-11-06.md) record the audit fixes and unresolved limits.
- **Human acceptance:** [clinical review pack](clinical-review/README.md), [staff/clinical decision register](clinical-staff-acceptance-register.json), and feature-specific policy/commissioning records. Technical success does not supply reviewer decisions.

Use the matrix above to record new scenario evidence for tasks, dictation, diagnostics/PDFs, records requests, stock/scanning and narcotics; relate each result to exact revision, target, role and feature state.
