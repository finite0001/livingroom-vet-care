Same screen, pocket size. Big tap targets, one job per row, and the actions a tech actually uses mid-house-call.

What Direction C changes, and why (from the swarm audit)

  • Onboarding is baked into the UI: a morning checklist narrates the day (“resend 2 failed messages”) instead of expecting a new hire to already know what an outbox failure is.
  • One primary action per screen: the audit found tasks buried under 15-field dialogs and three look-alike recovery buttons; here every card offers a single obvious next step.
  • Sentences, not system words: “Refill waiting” beats “RX request pending approval”, “Match inquiry” beats “assign unmatched inbound” — day-one readable.
  • Phones are first-class: the audit found 28–32px touch targets and Clients/Patients hidden behind “More”. This direction ships a real mobile layout with 44px+ targets everywhere.
  • Humane affordances: “Running late” is a first-class button — house calls run late; software that admits it earns trust on day one.
  • Helpful empty/full states: the checklist celebrates done steps, and every row explains itself, replacing the audit’s “dead-end empty states”.
