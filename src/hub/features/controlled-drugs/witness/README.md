# Independent controlled-stock witness

This frontend implements the closed six-RPC C2 contract. A qualified second staff member discovers eligible preparations, reads the complete immutable eight-field source projection, explicitly acknowledges witnessing it, and saves after a fresh lossless read under the same captured identity and original 30-second deadline. The recorder separately rereads their owned preparation and witness status before execution. There is no none-witness downgrade, automatic attestation, physical fact default, SDK mutation fallback, or identity substitution.

Only the seven identifying pointer fields persist in the browser. A lost save is resolved by explicit operation read or atomic closure. Not-found retains IDs; saved or abandoned clears only after strict reply and receipt admission. Session changes mask earlier details and checkbox state. The recorder's existing closed reply is unchanged; the separate status is guidance and the server must independently enforce witness eligibility and source equality.

Production endpoints and the new 121-relation backend kernel require independent source, SQL, real Auth, concurrency and actual acceptance. This frontend and its synthetic fixtures do not establish those gates. Missing/blocked/error responses fail closed. Original recorder none-witness behavior and original numeric/timestamp source preimages are retained.

Portable unit tests include 22 independently constructed receipt frames and digests, explicit fresh read/save, source/session/deadline refusals, ID-only recovery and recorder C2 enforcement. Mounted browser fixtures use explicit injected synthetic HTTP and session sources; they make no genuine Auth or physical-observation claim. Browser execution is a separate review step.
