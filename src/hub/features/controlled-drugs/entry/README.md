# Controlled-stock entry host

The ten original writer APIs call the same four-argument gateway with their complete named arguments, render-captured actor/session/generation, and a synchronous result admission callback. There is no direct canonical-write fallback. The authenticated AppShell mounts one provider outside the pathname-keyed content.

The provider probes the original intent first. A source-proven unmanaged reply submits the exact original named-argument body with that captured staff bearer. Unmanaged uncertainty remains with the original writer's same-intent explicit retry/recovery contract; no C0 journal or fake closure is invented. A managed reply opens an explicit physical allocation form. Quantities, observed time, custody, container creation and assertion confirmation are not prefilled. Preparing is followed by a separate immutable-preparation review and a later deliberate execute action. The preparation's six frozen fields and full original request remain inspectable. Witness-required responses are refused; this package does not implement independent physical witnessing.

A managed six-field ID-only pointer is persisted before prepare. All mutations use a per-actor Web Lock and refuse if the lock is unavailable. After an unknown result, the same operation is read before another decision; no automatic prepare/execute retry occurs. Global recovery is independent of native read-only receipt recovery. It accepts only complete owned saved/abandoned responses; expired/stale/not-found preparations remain owned until explicit close. A new session for the same actor may recover the original preparation; it is never equated to the preparation's old session. Actor, session and generation are checked across every await. Prior-session modal data is masked immediately.

The raw client enforces one fixed 30-second call deadline, raw16MiB/parsed2MiB replies, duplicate-key/UTF8/number-token preservation, and original request caps. The options' four-field string-version head DTO is distinct from the original preparation/receipt's full six-column source head and native bigint number. Managed delivery binds writer, operation and complete legacy/canonical intent, validates saved source/receipt/result relationships, and invokes the caller's strict adapter before clearing recovery IDs. An adapter or cleanup failure retains recovery; a post-write callback cannot impersonate a safe cancellation.

Production uses fixed public Supabase configuration and native fetch. Optional provider connection/fetch dependencies are explicit pure injection for the synthetic browser fixture; they do not enable a test mode, change authentication or add a write fallback. The session broker remains the actual context receiver.

Offline verification: 15 new client/service/plan/codec tests, six existing legacy boundary tests, seven anesthesia integration tests; target ESLint and application TypeScript passed during authoring. Six Playwright scenarios exercise the actual mounted provider with synthetic HTTP: explicit plan/review, lost-response recovery without resend, callback failure, same-actor new-session masking, phone flow and unavailable witness workflow. They are authored for Root to run; no service or browser was launched by this author.

Backend probe/journal/facade emission, live source/permission validation, independent witness software and genuine Auth/SQL acceptance remain separate. These frontend tests do not supply them. There is no signing, physical-practice, production or count activation claim.
