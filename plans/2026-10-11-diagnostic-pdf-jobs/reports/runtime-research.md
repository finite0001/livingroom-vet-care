# Renderer and byte-recovery research

Existing estimate publications persist exact immutable bytea before publication. Attachment capture adds reserved private paths, leases and actual-byte readback. Service-role Storage upload bypasses staff-JWT RLS; the future coordinator therefore needs unique immutable paths and explicit stale-worker/orphan handling. 3B1 saves exact bytes before upload and never claims readiness.

The existing Vercel team is Pro, verified read-only; no Sandbox/registry/deployment/resource was provisioned for this research. [Sandbox](https://vercel.com/docs/sandbox) provides a Firecracker boundary and [deny-all network/DNS](https://vercel.com/docs/sandbox/concepts/firewall). [Custom images](https://vercel.com/docs/sandbox/concepts/images) require linux/amd64; local Docker is arm64, so local architecture alone does not prove hosted parity. Playwright [chromiumSandbox defaults false](https://playwright.dev/docs/api/class-browsertype#browser-type-launch-option-chromium-sandbox); the existing Mac spike is not a sandbox proof. Require explicit non-root sandboxing, pinned images/fonts, credential-free inputs and externally enforced time/memory limits.

[Function bodies are limited to 4.5 MB](https://vercel.com/docs/functions/limitations). 3B1 caps captured bytes at 3 MiB so base64 plus binding metadata remains bounded; this is a recovery-journal limit, not a measured renderer admission guarantee. [Pricing](https://vercel.com/docs/sandbox/pricing), remaining credit, feature access and paid worker activation must be reviewed with the actual deployed candidate in 3B2.

[pdf-lib 1.17.1](https://github.com/Hopding/pdf-lib/releases/tag/v1.17.1) supplies a pure JS parser, but [its pinned parser](https://github.com/Hopding/pdf-lib/blob/v1.17.1/src/core/parser/PDFParser.ts) repairs/skips malformed inputs. Duplicate objects/keys and permissive parsing prevent treating page count or post-parse catalog inspection as complete security validation. Use a narrowly admitted renderer syntax plus bounded isolated parsing and actual-byte hash/page checks. The capture format marker in 3B1 is explicitly not this validation; no capture is ready, uploaded or exportable.
