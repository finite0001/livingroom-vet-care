# Authenticated shared-workspace browser proof

The completed local test exercised real staff login, the shared review queue and
dialog, one explicit signature, a deliberately lost successful response, reload
and explicit recovery of the original saved result. Opening either dialog and
acknowledging the evidence sent no mutation. Reload displayed the expected native
leave-page warning. All original rows, declared Auth/audit changes and owned
service cleanup passed. The test used only disposable synthetic local data.

The parent completed in 292.416987917 seconds; the browser phase completed in
37.738875583 seconds. Five browser business calls and 28 parent HTTP calls are
separate counts. The independent retained-artifact review reports 49 checks. This
is one finite engineering path, not full Auth/protocol/native/clinical acceptance
or permission to mount the signing workflow in production.

No raw Auth bodies, passwords, tokens, browser storage/input, screenshots or raw
clinical/business response bodies are copied from the run. The source-only
authority binding records the local dependency and Chromium trees by hash; those
installed tools and binaries are not distributed here.

Verify the fixed source archive from the repository root:

```sh
python3 -I -B evidence/controlled-record-review/shared-workspace-sdk-v1/verify.py
```

The verifier checks the original source maps, complete archive membership and
every source byte hash. It never extracts or executes archived code, reads the
historical absolute source/tool paths, starts services or contacts a provider.
Historical paths inside the unchanged source and binding are provenance, not
commands to run in a fresh checkout.

## Reproduction limits

The source archive is historical byte preservation. It does not preserve inode
identities or admit this checkout as the original runtime. Its frontend was the
frozen `f74974ac0700f28521ff5603d7059f80ebc79fd2` workspace tree; the same workspace
source later landed in PR 304 after an ancestry-only rebase and squash merge.
No active application, migration, grant, route, dependency or runtime is replaced
by this archive.

A fresh execution requires a separately reviewed placement/entry and physical
tool/source admission. The archived fixed runtime binds the original local
frontend placement, Node/Chromium and installed dependency tree. Do not rewrite
its binding or replace an expected hash with an observed value to make it run.
This package introduces no generic runner, Linux/CI execution or fresh browser
acceptance claim.

The original protected run remains `lrv-closed-lifecycle-jy11gnsi` in the local
temporary evidence directory. Its raw private bodies remain outside Git. The
archived independent review identifies the original outer session/chunk and
explains the distinction between recorded checks and independently reconstructed
timing or host guarantees. Earlier failed attempts remain preserved separately.
